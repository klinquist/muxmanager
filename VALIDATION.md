## Remaining device checks

Run on an iPhone and iPad, including landscape, a hardware keyboard, software keyboard, and iPad split view.

- Create an Ed25519 key, copy its public key to a test host, and connect. Import unencrypted and passphrase-protected Ed25519/RSA OpenSSH keys. Invalid formats/passphrases must fail visibly.
- Connect directly and through a separately authenticated bastion to Linux and macOS. Verify both host fingerprints. A changed key must stop connection until explicitly trusted.
- Connect a desktop terminal to the same tmux window at a known size. Select Smart and Original, switch windows, rotate, show/hide the keyboard, and zoom. Desktop dimensions and selected window must not change.
- Select Fit. Only the chosen remote window should resize. Leave Fit, switch windows, background, and disconnect. The previous sizing policy should return while connected. Resize from the desktop during Fit and ensure the app relinquishes stale restoration.
- Drop the network or force-terminate during Fit, then reconnect. Restore only if the same tmux server and the app's dimensions/policy remain. Restart tmux before reconnecting and ensure the old lease is ignored.
- Use duplicate window names, several sessions, external create/rename/close operations, no sessions, and hosts without compatible tmux. Select by stable IDs; missing windows must stop accepting input.
